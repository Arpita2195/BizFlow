# BizFlow — All-in-One Business Management Platform

BizFlow is a premium all-in-one business management platform featuring a full Vite + React client and an Express + MongoDB backend with full Nodemailer SMTP integration, customer portal, RBAC access control, and messaging capabilities.

## Key Features

- **Landing & Public Marketing**: Dynamic showcase with live contact form dispatching notifications directly to `arpitanathwani2195@gmail.com`.
- **Authentication & Roles**: Multi-role access control (Owner, Manager, Staff) with JWT authentication.
- **Client & Customer CRM**: Manage customers, bookings, quotes, invoices, expenses, loyalty points, and staff.
- **Direct Messaging & Invoicing**: Send bills/invoices via WhatsApp (`+91 9099314955`) & Nodemailer Email.
- **Promotional Broadcasts**: Send targeted campaign discounts via email.
- **Database & Cloud Integration**: Connected with MongoDB Atlas cluster database.
